# RoPE (Rotary Position Embedding / 回転位置埋め込み) の解説

現代の主要なオープンソース LLM（**LLaMA 1/2/3**, **Mistral**, **Qwen**, **Gemma** など）で **事実上の標準（デファクトスタンダード）** として使われている位置埋め込み技術 **RoPE (Rotary Position Embedding)** について解説します。

---

## 1. 結論：RoPE とは？

**「ベクトルを位置に応じてクルッと回転（Rotate）させるだけで、相対的な距離感を自然に表現できる技術」** です。

2021年に Jianlin Su 氏らによって提案された手法で、絶対位置埋め込みの扱いやすさと、相対位置埋め込みの長文への強さを**完全融合**させた革新的な技術です。

---

## 2. 直感的なイメージ：なぜ「回転」なのか？

単語のベクトルを 2 次元平面上の **「矢印（針）」** に例えて考えてみます。

```text
 ［ 単語 A ］ (位置 1): 針を 10度 回転させる ──> ↗
 ［ 単語 B ］ (位置 3): 針を 30度 回転させる ──> ↖
```

位置 $m$（1文字目、2文字目...）に応じて、ベクトルを**一定の角度（$m \times \theta$）だけ回転** させます。

### 💡 魔法のような数学的性質
2 つのベクトル同士の類似度（ドット積 / 内積）を計算すると、三角関数の性質によって **「2つの回転角の引き算（角度の差）」だけが綺麗に残ります。**

$$\text{回転の差} = (30^\circ - 10^\circ) = 20^\circ \quad (\text{相対距離 } 3 - 1 = 2 \text{ 分の開き})$$

つまり、**単語ベクトルを回転させるだけで、アテンション計算（内積）をした瞬間に「2つの単語がどれくらい離れているか（相対距離）」が勝手に浮き出てくる** という仕組みになっています。

---

## 3. RoPE が現代の LLM で大採用されている 3 大メリット

### ① 絶対位置の扱いやすさ ＋ 相対位置の精度のイイコト取り
* ベクトルへの適用自体は、各単語の位置 $m$ に応じて回転させるだけ（実装がシンプル）。
* アテンション計算をすると、自動的に「単語同士の離れ具合（相対位置）」が評価される。

### ② 未知の超長文への拡張性 (RoPE Scaling / 外挿性)
学習時に 4,096 トークンまでしか学習していなくても、回転させる角度のスケールを調整（RoPE Scaling / YaRN など）することで、推論時に **32,000 トークンや 128,000 トークンといった超長文まで後から簡単に拡張** できます。

### ③ メモリ・計算コストが非常に低い
BERT のように「位置 0 用のベクトル、位置 1 用のベクトル...」という巨大な位置埋め込みテーブルをメモリ上に保持する必要がありません。単語ベクトルに対して簡単な回転行列を掛けるだけで済むため、非常に省メモリかつ高速です。

---

## 4. 位置埋め込みの発展とモデル比較

| 方式 | 代表モデル | 特徴 |
| :--- | :--- | :--- |
| **学習可能・絶対位置** | BERT, GPT-2 | 位置ごとに固定ベクトルを足す。実装は簡単だが長文に弱い。 |
| **相対位置 (アテンション改修)** | T5, DeBERTa | アテンション計算式の中に距離項目を追加。高精度だが計算が重い。 |
| **RoPE (回転位置埋め込み)** | **LLaMA 3**, **Mistral**, **Gemma**, **Qwen** | **ベクトルを回転させる。超高速・省メモリ・長文拡張性が最強。** |

---

## 5. まとめ

* **RoPE**: ベクトルを位置の数だけ回転（Rotate）させて埋め込む技術。
* **特徴**: 内積を取ると「単語間の距離」が自動的に浮き出る数学的マジック。
* **現状**: 現代のほぼすべての最新LLM（LLaMAシリーズ等）で標準採用されている、最も重要な要素技術の1つです。
