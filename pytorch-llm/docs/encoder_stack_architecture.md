# エンコーダスタック (Encoder Stack) の意味と内部構造

オライリー本第3章（62〜63ページ）の図3-1に登場する **「エンコーダスタック (Encoder Stack)」** の定義、役割、および内部構造について解説します。

---

## 1. 結論：「エンコーダスタック」とは？

「スタック (Stack)」とは英語で **「積み重ね」「重ね合わせ」** を意味します。

**エンコーダスタック** とは、同じ基本構造を持つ **「エンコーダ層（Encoder Block）」を重箱のように何層も縦に連続して積み重ねた（スタックした）ブロック全体** のことです。

```text
 ［ 入力埋め込みベクトル ］ (トークン + 位置)
         │
         ▼
┌────────────────────────────────┐
│  エンコーダ層 (Layer 1)        │
├────────────────────────────────┤
│  エンコーダ層 (Layer 2)        │  <-- これら同じ構造の層を
├────────────────────────────────┤      何層も積み重ねた（スタックした）
│  ...                           │      全体の集合体を
├────────────────────────────────┤      「エンコーダスタック」と呼ぶ
│  エンコーダ層 (Layer N)        │      (例: BERT-baseなら 12層)
└────────────────────────────────┘
         │
         ▼
 ［ 研ぎ澄まされた隠れ状態 (Context) ］
```

---

## 2. 1つの「エンコーダ層 (Encoder Block)」の内部構造

スタックされている1つひとつの「エンコーダ層」の中には、主に以下のパーツが入っています。

```text
  ┌────────────────────────────────────────────────┐
  │  【1つ分のエンコーダ層 (Encoder Layer)】       │
  │                                                │
  │   1. Multi-Head Self-Attention 層              │
  │      (単語同士の関係性・文脈を計算する)        │
  │   2. Add & Norm (残差接続 ＋ LayerNorm)        │
  │   3. Feed-Forward 全結合層 (FFN)               │
  │      (文脈情報を知識と照合し非線形変換する)     │
  │   4. Add & Norm (残差接続 ＋ LayerNorm)        │
  └────────────────────────────────────────────────┘
```

各モデルで何層積み重ねられているかの例：
* **DistilBERT**: 6 層のスタック
* **BERT-base**: 12 層のスタック
* **BERT-large**: 24 層のスタック

---

## 3. なぜ「スタック（何層も重ねる）」にするのか？

1層だけでは、文章の浅い文脈（隣の単語との関係など）しか理解できません。

層を何層もスタックして通過させることで、データが下層から上層へと伝わるにつれて、以下のように表現が段階的に深化していきます。

* **下位層 (1〜3層目)**: 構文や隣接する単語同士の文法的なつながりを捉える
* **中位層 (4〜8層目)**: 意味的な文脈や句の構造を捉える
* **上位層 (9〜12層目)**: 文章全体の大まかな意図、複雑な感情、高度な抽象表現を捉える

画像認識の CNN が「点・線 ──> 目や鼻 ──> 顔全体」と深い層になるほど高度な概念を捉えるのと同様に、NLPのエンコーダスタックも **「層を重ねるほど文章の深い意味を抽出できる」** という仕組みになっています。

---

## 4. まとめ

* **エンコーダ層**: Self-Attention と FFN からなる基本ユニット。
* **エンコーダスタック**: その基本ユニットを 6層や12層など**縦に連結・積層したエンコーダの本体部分**のこと。
* **目的**: 単語ベクトルを通過させながら、文章全体の文脈が深く凝縮された「隠れ状態（コンテキスト）」を作り出すこと。
