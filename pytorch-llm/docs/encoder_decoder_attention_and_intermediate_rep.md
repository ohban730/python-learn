# エンコーダ・デコーダアテンション層と「中間表現」の解説

オライリー本第3章（81ページ）に登場する **「中間表現」** という用語の意味と、デコーダにおける第2のサブレイヤー **「エンコーダ・デコーダアテンション層 (Cross-Attention)」** の仕組みを解説します。

---

## 1. マスク付きセルフアテンションについて
ご認識の通り **100% 正解** です！
「マスク付きマルチヘッドセルフアテンション」は、未来の単語をカンニングしないように遮断（マスク）する **Causal Attention（因果的アテンション）** と全く同じものです。

---

## 2. 「中間表現 (Intermediate Representation)」とは何のこと？

言葉は難しく見えますが、意味はシンプルです。

**中間表現** とは、**「デコーダブロックの処理の途中で計算された、最新の隠れ状態（ベクトルデータ）」** のことです。

```text
 ［ 生成中のテキスト (例: "I have a") ］
                    │
                    ▼
 ［ ① マスク付きセルフアテンション層 ］ を通過
                    │
                    ▼
 ★ ［ デコーダの中間表現 ］ = 「"I have a" の次に来る名詞を探している」という最新の記憶ベクトル
```

この「第1サブレイヤーを通った直後の最新ベクトル（中間表現）」が、次の「エンコーダ・デコーダアテンション」で **Query (クエリ / 問い)** として使われます。

---

## 3. 「エンコーダ・デコーダアテンション層」とは何か？

別名 **クロスアテンション (Cross-Attention)** とも呼ばれ、**「原文の情報（エンコーダ）」と「生成中の訳文の情報（デコーダ）」を結びつける架け橋** の役割を果たす層です。

この層の最大の特徴は、**Query、Key、Value の由来が異なる** 点です。

```text
       【 エンコーダ側 (原文) 】                    【 デコーダ側 (生成中) 】
  (例: 「私は ペンを 持っています」)                 (例: "I have a" まで生成完了)
                │                                           │
                ▼                                           ▼
       ［ エンコーダの出力 ］                    ［ ①マスク付きアテンション通過 ］
        │              │                                    │
        ▼ (Keyにする)   ▼ (Valueにする)                      ▼ (Queryにする)
     Key (K)        Value (V)                       Query (Q)
        │              │                                    │
        └──────────────┼────────────────────────────────────┘
                       ▼
      ★ ［ エンコーダ・デコーダアテンション層 ］
         (Query を使って、原文の Key/Value にアテンションを計算！)
```

### Q, K, V の役割分担
* **Query (クエリ / 問い)** ── **デコーダの中間表現**
  * 「今 "I have a" まで書いたよ！次に入る名詞は原文のどれ？」という問いかけ。
* **Key (キー / 見出し)** ── **エンコーダの出力**
  * 原文の全単語（「私」「ペン」「持って」「います」）の見出し。
* **Value (バリュー / 中身)** ── **エンコーダの出力**
  * 原文の全単語の具体データ。

---

## 4. デコーダブロック全体のまとめ

デコーダ1個のブロックの中には、役割の異なる **2種類のアテンション** が順番に入っています。

1. **マスク付きセルフアテンション (Causal Attention)**
   * 自分（デコーダ自身）が過去に生成した単語同士の関係を整理する。
   * ここでできたベクトルが **「中間表現」** となる。
2. **エンコーダ・デコーダアテンション (Cross-Attention)**
   * 上記でできた「中間表現 (Query)」を使って、原文（エンコーダの Key/Value）を見に行き、**「原文のどこに注目して次の単語を訳せばいいか」** を確定させる。
