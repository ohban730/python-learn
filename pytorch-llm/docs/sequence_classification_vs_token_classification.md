# 系列分類 (感情分類) と トークン分類 (固有表現認識) のアプローチ比較

オライリー本第4章（101〜102ページ）で解説されている **「感情分類」と「固有表現認識 (NER)」のアプローチがなぜ同じと言えるのか** について、共通点と唯一の違いを整理して解説します。

---

## 1. 結論：何が同じで、何が違うのか？

両者のアプローチは **基本構造（Transformer ＋ 全結合層 `nn.Linear` で分類する）が全く同じ** です。

唯一の違いは、**「文章全体で 1 回だけ分類するのか」** か **「各単語ごとに人数分（N回）分類するのか」** という範囲の違いだけです。

```text
 ■ 1. 系列分類 (感情分類 / 第2章)
   [文章全体] ──> [ Transformer ] ──> ［ [CLS] ベクトル 1個 ］ ──> [ nn.Linear ] ──> 1つの予測 (例: ポジティブ)

 ■ 2. トークン分類 (固有表現認識 / 第4章)
   [単語1: 田中] ──> [ Transformer ] ──> ［ 単語1のベクトル ］ ──> [ nn.Linear ] ──> B-PER (人名)
   [単語2: が  ] ──> [ Transformer ] ──> ［ 単語2のベクトル ］ ──> [ nn.Linear ] ──> O     (その他)
   [単語3: 東京] ──> [ Transformer ] ──> ［ 単語3のベクトル ］ ──> [ nn.Linear ] ──> B-LOC (地名)
```

---

## 2. ２つのタスクの比較表

| 項目 | 系列分類 (感情分類 / 2章) | トークン分類 (固有表現認識 / 4章) |
| :--- | :--- | :--- |
| **英語名** | Sequence Classification | Token Classification |
| **入力データ** | 文章全体のテキスト | 文章全体のテキスト |
| **特徴量の抽出先** | **`[CLS]` トークンの隠れ状態のみ** (1個) | **全単語（トークン）の隠れ状態** (N個) |
| **分類器 (`nn.Linear`)** | 1 回だけ適用する | **各単語に対してそれぞれ適用する** (同じ重みを使い回す) |
| **出力結果** | 1つのラベル (例: `joy`) | 単語数分のラベル (例: `[B-PER, O, B-LOC]`) |

---

## 3. 学校のクラスで考える例え話

* **感情分類 (系列分類)**:
  「クラス全体の学力レベル」を判定したいとき、**クラス代表（`[CLS]` トークン）1人だけにテストを受けさせて**、クラス全体の成績（ポジティブ/ネガティブ）を決める方法。
* **固有表現認識 (トークン分類)**:
  「生徒一人ひとり（各単語）の得意科目」を判定したいとき、**全員に同じテスト問題（全結合層 `nn.Linear`）を配って**、一人ひとりの性格（人名/地名/普通名詞）を決める方法。

---

## 4. まとめ

* **道具は全く同じ**: どちらも「Transformerエンコーダで隠れ状態を作り、その上に全結合層 `nn.Linear` を載せる」という構造。
* **同じと言われる理由**: 固有表現認識（NER）は特別な技術を使っているわけではなく、**「全単語の隠れ状態に対して、感情分類と同じ全結合層を一斉に適用しているだけ（トークン単位の分類）」** だからです。
