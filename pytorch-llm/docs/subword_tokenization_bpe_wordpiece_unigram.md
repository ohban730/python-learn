# サブワード・トークン化手法 (WordPiece / Unigram / BPE) の解説

オライリー本第4章（99ページ）に登場する **WordPiece** や **Unigram** がどのようなエンコーディング（トークン化）手法なのか、代表的な 3 大アルゴリズム（BPE, WordPiece, Unigram）を比較して解説します。

---

## 1. 結論：どちらも「サブワード (Subword) トークン化」アルゴリズムです

WordPiece も Unigram も、**単語（Word）と文字（Character）の中間である「サブワード（単語の断片）」** にテキストを分割して数値化するエンコーディング手法です。

### 💡 なぜサブワードに分割するのか？
* **単語単位（Word）**: 「playing」「played」「plays」を全部別々の単語として覚えると、辞書サイズが無限に巨大化し、辞書にない未知語（OOV）に対応できなくなる。
* **文字単位 (Character)**: 1文字ずつ（p-l-a-y-i-n-g）に分解すると辞書は小さくなるが、1文字だけでは意味を持たないため計算効率が悪い。
* **サブワード単位 (Subword)**: 「play ＋ ing」のように意味のある最小単位に分割することで、**小さな辞書サイズで未知語をゼロにしつつ、高度な意味を維持できる。**

---

## 2. 3 大サブワード・アルゴリズムの比較

サブワードを作るアプローチには、大きく分けて **「ボトムアップ型（文字から結合していく）」** と **「トップダウン型（巨大な辞書から削ぎ落とす）」** の 2 種類があります。

```text
 ■ ボトムアップ型 (BPE / WordPiece)
   [ p ] [ l ] [ a ] [ y ] ──> 頻度の高いペアを合体 ──> [ play ] + [ ing ]

 ■ トップダウン型 (Unigram)
   ［ あらゆる組み合わせの巨大辞書 ］ ──> 確率が低い不要なトークンを削除 ──> 最適な辞書
```

---

## 3. 各手法の詳細と特徴

| アルゴリズム | アプローチ | 代表的なモデル | 仕組みと特徴 |
| :--- | :--- | :--- | :--- |
| **WordPiece** | **ボトムアップ**<br>(結合型) | **BERT**<br>DistilBERT | 1文字単位からスタートし、ペアにした時に **「最も情報量（対数尤度）が増えるペア」** を順番に合成して辞書を作る。<br>※語幹と接頭辞（例: `play` ＋ `##ing`）に分解されやすい。 |
| **Unigram** | **トップダウン**<br>(削減型) | **SentencePiece**<br>XLM-RoBERTa, T5 | 最初に可能な限り巨大な単語辞書を用意し、**「消しても言語モデルの確率（損失）に影響が少ない不要なトークン」** を順番に削ぎ落として辞書を作る。 |
| **BPE** | **ボトムアップ**<br>(結合型) | **GPT-2/4**<br>RoBERTa, LLaMA | 1文字単位からスタートし、コーパス内で **「一番高頻度で隣り合っているペア」** を単純に結合していく。 |

---

## 4. まとめ

* **WordPiece** (BERTなどで使用): 文字から出発し、意味の情報量が最大になるようにトークンを**合体させていく**手法。
* **Unigram** (SentencePieceなどで使用): 巨大な辞書からスタートし、確率モデルに基づいて不要なトークンを**削ぎ落としていく**手法。

どちらも「未知語（OOV）を出さずに効率よくテキストをベクトル化する」という目的を達成するための優れたサブワード分割アルゴリズムです。
