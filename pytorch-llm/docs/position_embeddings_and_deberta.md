# 位置埋め込み (Positional Embedding) と DeBERTa モデルの徹底解説

オライリー本第3章（78〜79ページ）に登場する **「位置埋め込み（絶対位置・相対位置）」の仕組み** と、そこで紹介されているモデル **「DeBERTa (デバータ)」** について解説します。

---

## 1. なぜ「位置埋め込み (Positional Embedding)」が必要なのか？

### 💡 根本的な理由：Self-Attention には「単語の順番」という概念がないから

Transformer の Self-Attention は、すべての単語同士の関係性を一括で同時に計算します。そのため、**単語の並び順（順番）の情報を自力で知ることができません。**

```text
  文章 A: 「犬 が 猫 を 追いかける」
  文章 B: 「猫 が 犬 を 追いかける」
```

人間にとっては全く意味が異なりますが、Self-Attention にとっては単語の集合（`犬`, `猫`, `が`, `を`, `追いかける`）が同じに見えてしまいます。

この弱点を補うために、**「この単語は 0 番目」「この単語は 1 番目」という順序情報を数値（ベクトル）にして単語ベクトルに足し算する** のが「位置埋め込み」です。

```text
 ［ トークン埋め込み ］:  [ "猫" の意味ベクトル ]
            ＋
 ［ 位置埋め込み ］    :  [ "0番目の位置" のベクトル ]
            │
            ▼
 ［ 結合されたベクトル ］: 「0番目の位置にある 猫」という意味を持つベクトルが完成！
```

---

## 2. 位置埋め込みの 3 つのアプローチ

書籍78〜79ページで紹介されている 3 つの方式の違いです。

### ① 学習可能な絶対位置表現 (Learned Absolute Position) ★BERTなどの標準
* **仕組み**: 0番目、1番目、2番目... という絶対的な位置ごとに専用のベクトルを用意し、単語ベクトルに直接足し算する（`token_emb + pos_emb`）。
* **長所**: 直感的で実装が簡単。
* **短所**: 学習時に用意した最大長（例: 512文字）を超える長文が入力されると計算できない。

### ② 絶対位置表現 (正弦・余弦 / Sinusoidal) ★Transformer原論文
* **仕組み**: サイン・コサイン波の数式を使って、各位置に固定のパターン数値を割り当てる。学習データが少ない場合に有効。

### ③ 相対位置表現 (Relative Position) ★現代の主流 (DeBERTa / RoPEなど)
* **仕組み**: 「絶対的な何文字目か」ではなく、**「単語Aから見て単語Bはどれくらい離れているか（距離）」** をアテンション計算時に考慮する。
* **長所**: 未知の長文にも対応しやすく、単語同士の距離感が正確に捉えられる。

---

## 3. DeBERTa (デバータ) とはどんなモデル？

書籍79ページに登場する **DeBERTa**（**De**coded **BERT** with **D**isentangled **A**ttention）は、Microsoft が開発した **BERT の進化形（上位互換）モデル** です。

```text
  BERT     : 「単語の意味」と「単語の位置」を最初にごちゃ混ぜ（足し算）にして処理する
  DeBERTa  : 「単語の意味」と「単語の位置」を分離（Disentangle）して別々に高度に計算する！
```

### 🌟 DeBERTa の 2 大イノベーション

1. **分離型アテンション (Disentangled Attention)**
   単語の「意味 (Content)」と「位置 (Position)」を別々のベクトルとして扱い、アテンション計算の際に以下の相互関係を精密に計算します。
   * 「意味 × 意味」（例: `犬` と `追いかける` の関連性）
   * 「意味 × 位置」（例: `犬` から見た距離感）
   * 「位置 × 意味」（例: 2番目の位置と `猫` の関係）
2. **人間のスコアを超えた実績**
   DeBERTa は登場当時、自然言語理解の総合ベンチマークテスト（GLUE）において、**史上初めて人類の平均スコアを上回ったモデル** として非常に有名になりました。

---

## 4. まとめ

* **位置埋め込み**: 順序概念を持たない Transformer に「単語の順番・位置」を教えるための必須の仕組み。
* **DeBERTa**: 単語の意味と位置を分離してアテンション計算する「相対位置表現」を取り入れ、BERTの精度を大幅に塗り替えた先進的モデル。
