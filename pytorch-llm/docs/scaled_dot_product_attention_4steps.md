# スケール化ドット積アテンション (Scaled Dot-Product Attention) の 4 ステップと射影の仕組み

オライリー本第3章（66〜67ページ）に登場する **「スケール化ドット積アテンション」** の4つの実装ステップの図式化と、**「クエリ (Query)・キー (Key)・バリュー (Value) への射影 (Projection)」** の概念についてわかりやすく解説します。

---

## 1. 「射影 (Projection)」とは？ なぜ Q, K, V の 3 つに分けるのか？

アテンション機構に入る直前、入力された単語の埋め込みベクトル $X$ に対して、3 つの異なる重み行列（$W_Q, W_K, W_V$）を掛け算して **$Q, K, V$ という 3 種類のベクトルに変換（射影）** します。

$$\text{Query (Q)} = X \cdot W_Q, \quad \text{Key (K)} = X \cdot W_K, \quad \text{Value (V)} = X \cdot W_V$$

### 💡 検索エンジン（図書館）で考える例え

| ベクトル | 役割 | 検索エンジンの例え |
| :--- | :--- | :--- |
| **Query (Q)** | **問い・探している情報** | 検索窓に入力する **検索キーワード** |
| **Key (K)** | **インデックス・見出し** | Webページや書籍の **タイトル・タグ** |
| **Value (V)** | **実際のコンテンツ** | Webページや書籍の **本文・中身** |

### ❓ なぜ 1 つのベクトル $X$ のまま計算しないのか？
単一のベクトル $X$ のままだと、「情報を探す顔（問い）」と「探される顔（見出し）」と「中身の情報」が混ざってしまいます。
3つの重み行列を使って異なるベクトル空間に **プロジェクション（射影）** することで、それぞれの役割に特化した最適な表現を作ることができます。

---

## 2. スケール化ドット積アテンションの 4 ステップ図式化

アテンションの数式：
$$\text{Attention}(Q, K, V) = \text{softmax}\left( \frac{Q \cdot K^T}{\sqrt{d_k}} \right) V$$

```text
  ［ 入力埋め込み X ］
         │
         ├─────────────────────────┬─────────────────────────┐
         ▼ (× W_Q)                 ▼ (× W_K)                 ▼ (× W_V)
 ┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐
 │   Query (Q)     │       │    Key (K)      │       │   Value (V)     │  <-- 【Step 1: 射影】
 └────────┬────────┘       └────────┬────────┘       └────────┬────────┘
          │                         │                         │
          └───────────┬─────────────┘                         │
                      ▼                                       │
         ［ 類似度 (Q × K^T) の計算 ］                        │  <-- 【Step 2: アテンションスコア】
                      │                                       │
                      ▼                                       │
         ［ √d_k で割ってスケーリング ］                      │
                      │                                       │
                      ▼                                       │
         ［ Softmax で正規化 (合計=1.0) ］                    │  <-- 【Step 3: アテンションの重み】
                      │ (アテンションの重み α)                │
                      └──────────────────┬────────────────────┘
                                         ▼
                         ［ 重み α × Value (V) の加重平均 ］  <-- 【Step 4: 埋め込みの更新】
                                         │
                                         ▼
                         ［ 新しい文脈付きベクトル Z ］
```

---

## 3. 各ステップの詳しい動作解説

### Step 1: クエリ・キー・バリューへの射影 (Projection)
* **処理**: 入力ベクトル $X$ にそれぞれ重み行列 $W_Q, W_K, W_V$ を掛け算し、アテンション計算専用の $Q, K, V$ を生成します。

### Step 2: アテンションスコア（類似度）の計算
* **処理**: クエリ $Q$ と キー $K$ の転置行列（$K^T$）の**内積（ドット積）** を計算します（$Q \cdot K^T$）。
* **意味**: 「単語AのQuery」と「全単語のKey」がどれくらい似ているか（関係が深いか）を数値化します。似ている単語同士は内積の値が大きくなります。

### Step 3: スケール化 ＋ Softmax（アテンションの重みの算出）
* **処理① (スケーリング)**: ドット積の値を $\sqrt{d_k}$（キーの次元数のルート）で割ります。
  * **理由**: 次元数 $d_k$ が大きくなるとドット積の値が膨大になり、Softmax の勾配が極端に小さくなって学習が停止する（勾配消失）のを防ぐため。
* **処理② (Softmax)**: Softmax 関数に通して、各単語への注目の割合（合計が `1.0` / 100% になる確率分布）に変換します。

### Step 4: バリューベクトルとの加重平均（トークン埋め込みの更新）
* **処理**: Step 3 で求めた注目の割合（重み $\alpha$）を、バリュー $V$ に掛け算して足し合わせます（加重平均）。
* **意味**: 関連性の高い単語の Value 情報（中身）を多く取り込んだ、**文脈情報を反映した新しいベクトル $Z$** を出力します。

---

## 4. まとめ

1. **射影 (Step 1)**: 入力を役割の異なる $Q, K, V$ に変身させる。
2. **スコア計算 (Step 2)**: $Q \times K^T$ で「どこに注目すべきか」の類似度を計算。
3. **スケール＆Softmax (Step 3)**: 勾配消失を防ぐために割った後、合計 100% の割合に変換。
4. **加重平均 (Step 4)**: 割合に応じて $V$ の中身を混ぜ合わせ、文脈付きの新しいベクトルを生成。
