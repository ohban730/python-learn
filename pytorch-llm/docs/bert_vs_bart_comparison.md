# BERT と BART の違い (名前は似ているが別のモデル？)

書籍の63ページに登場する **BERT** と **BART** の違いについて解説します。

---

## 1. 結論：名前は非常に似ていますが、構造（タイプ）が全く異なる別のモデルです

どちらも Transformer をベースにしたモデルですが、**構成パーツが異なります。**

* **BERT** ── **エンコーダのみ (Encoder-only)**
* **BART** ── **エンコーダ・デコーダ (Encoder-Decoder)**

---

## 2. BERT と BART の比較表

| 項目 | BERT (バート) | BART (バート) |
| :--- | :--- | :--- |
| **開発元** | Google | Meta (Facebook) |
| **正式名称** | **B**idirectional **E**ncoder **R**epresentations from **T**ransformers | **B**idirectional and **A**uto-**R**egressive **T**ransformers |
| **アーキテクチャ** | **エンコーダのみ** | **エンコーダ ＋ デコーダ** |
| **仕組み** | BERTの「エンコーダ」単体 | BERT（エンコーダ） ＋ GPT（デコーダ）を合体させた「いいとこ取り」構造 |
| **得意分野** | テキスト分類、感情分析、検索、抽出 | **文章要約**、**機械翻訳**、文章の修正・補元 |

---

## 3. なぜ BART が作られたのか？ (BART の強み)

### BERT の弱点
BERT は「エンコーダのみ」なので、文章の意味を深く理解するのは超得意ですが、**「新しい文章をスムーズに書き出す（生成する）」ことは苦手** でした。

### BART の解決策
Meta の研究チームは、**「BERTの深い理解力（エンコーダ）」** と **「GPTの流暢な文章生成力（デコーダ）」** を結合した **BART** を開発しました。

```text
 ［ 入力文 (ノイズ入り) ］: 「私は 昨日 [削除] お寿司を 食べた。」
         │
         ▼
 【 BERT 型エンコーダ 】 ──> 前後から「削除されたのは場所（築地など）」だと深く理解する
         │
         ▼ (隠れ状態をデコーダへ渡す)
 【 GPT 型デコーダ 】   ──> 「私は昨日築地でお寿司を食べました。」と綺麗な文章を書き出す！
```

---

## 4. まとめ

* **BERT**: 「読む・理解する」専門モデル（テキスト分類など）。
* **BART**: 「読んで理解した上で、新しい文章を書く」両刀モデル（文章の要約や翻訳など）。

名前は1文字違いで似ていますが、**BART は BERT の理解力と GPT の生成力をガッチャンコした『エンコーダ・デコーダ型』モデル** という位置付けになります。
