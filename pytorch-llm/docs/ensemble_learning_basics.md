# アンサンブル学習 (Ensemble Learning) の仕組みと代表的手法

機械学習における非常に強力なアプローチである **「アンサンブル学習 (Ensemble Learning)」** について分かりやすく解説します。

---

## 1. 結論：アンサンブル学習とは？

音楽の「アンサンブル（合奏）」が語源であり、**「1つのモデルに頼るのではなく、複数のモデルを集めてチームを作り、みんなの意見（多数決や平均）を統合して最終判断を下す手法」** です。

ことわざの **「三人寄れば文殊の知恵」** を機械学習で数学的に実現した仕組みです。

```text
 ［ 従来の手法 ］:  1人の天才モデル ──> 単独で予測 (1人で間違えると即アウト)

 ［ アンサンブル学習 ］: 
    モデル 1 (予測: 喜び) ──┐
    モデル 2 (予測: 悲しみ) ──┼──> 【 多数決 / 平均 】 ──> 最終予測: 「喜び」 (安定して高精度!)
    モデル 3 (予測: 喜び) ──┘
```

---

## 2. なぜアンサンブル学習を行うと強くなるのか？

1. **うっかりミスの低減 (分散の減少)**:
   1つのモデルが勘違いして間違えたとしても、他のモデルが正しければ多数決で間違いをカバーできます。
2. **過学習 (Overfitting) の防止**:
   個々のモデルの「クセ」や「偏り」が互いに打ち消し合わされるため、未知のデータに対しても安定した性能を発揮できます。

---

## 3. アンサンブル学習の 3 大手法

作り方や組み合わせ方の違いによって、主に以下の 3 つの手法があります。

```text
 ① バギング (並列型)      ② ブースティング (直列・特訓型)    ③ スタッキング (まとめ役型)
  ┌─────┐ ┌─────┐ ┌─────┐   ┌───┐   ┌───┐   ┌───┐           ┌─────────┐ ┌─────────┐
  │木 A │ │木 B │ │木 C │   │木1│──>│木2│──>│木3│ (苦手克服)    │モデル A │ │モデル B │
  └──┬──┘ └──┬──┘ └──┬──┘   └───┘   └───┘   └───┘           └────┬────┘ └────┬────┘
     └───┬───┘   │                                               └────┬────┘
         ▼ (多数決)                                                   ▼ (まとめ役モデル)
       最終予測                                                     最終予測
```

### ① バギング (Bagging) ★代表例: **ランダムフォレスト**
* **仕組み**: データを少しずつランダムに変えて、複数のモデル（決定木など）を**独立・並列に学習**させ、最後に全員で**多数決**を取る。
* **特徴**: 安定感があり、過学習に非常に強い。

### ② ブースティング (Boosting) ★代表例: **XGBoost, LightGBM, CatBoost**
* **仕組み**: モデルを**順番（直列）に学習**させます。1つ目のモデルが間違えた難問データを、2つ目のモデルが重点的に復習・学習して弱点を補強していく。
* **特徴**: データ分析コンペ（Kaggle など）で表形式データにおいて最強の精度を叩き出す超人気アプローチ。

### ③ スタッキング (Stacking)
* **仕組み**: 種類の異なるモデル（例: ロジスティック回帰 ＋ ランダムフォレスト ＋ ニューラルネットワーク）の予測結果を、さらに別の「まとめ役モデル（メタモデル）」に入力して最終判断させる。

---

## 4. これまでの学習内容との繋がり

* **第2章の「ランダムフォレスト」**:
  100 本などの大量の「決定木」を並列で動かして多数決を取る、バギング型アンサンブル学習の代表格です。
* **「ドロップアウト (Dropout)」**:
  学習ごとにランダムに一部のニューロンをオフにすることで、**「1つのネットワーク内で無数の部分モデルのアンサンブル学習を行っている」** のと同じ効果を生み出しています。

---

## 5. まとめ

* **アンサンブル学習**: 複数のモデルの予測を合体（多数決・平均）させて精度を高める技術。
* **メリット**: 単体モデルよりも高精度になり、過学習を起こしにくく安定する。
