# 抽出型 QA (Extractive QA) におけるスパン分類と 3 つの課題の解説

> **📄 出典・参考情報**
> * **参考書籍**: 『機械学習エンジニアのためのTransformers』 (オライリー・ジャパン発行, ISBN: 978-4-87311-995-3)  
> * **該当箇所**: 7.1.2 節「テキストから回答を抽出する」 (pp.181-182)  
> * **著者**: Lewis Tunstall, Leandro von Werra, Thomas Wolf / 訳: 中山 光樹

## 💡 1. 結論：そもそもどうやって回答を出力（生成）させているのか？

**【核心の答え】 抽出型 QA では、モデルはテキストを「新しく生成」していません！**

モデル（XLM-RoBERTa や BERT など）が行っているのは、文章を自動生成することではなく、**「本文の中の何番目から何番目までが答えか」という【開始位置 (Start)】と【終了位置 (End)】の 2 つのインデックス番号を予測（範囲指定）しているだけ** です。

これを **スパン分類 (Span Classification)** と呼びます。

```text
 ［ 入力系列 ］: [CLS] Is it waterproof? [SEP] This watch is waterproof at 30m depth [SEP]
                                                   │         │                │
                                                   ▼         ▼                ▼
 ［ 開始確率 (Start) ］:                          0%       95% (最高!)       0%
 ［ 終了確率 (End) ］  :                          0%        0%              92% (最高!)

 ［ システムの処理 ］: 開始 95% (waterproof) 〜 終了 92% (30m) の範囲を切り抜く！
 ［ 最終回答 ］: "waterproof at 30m"
```

モデルは単語を一から生成するのではなく、**本文トークンの中から「スタート位置」と「ゴール位置」の2つの数字を弾き出しているだけ** なので、ハルシネーション（嘘）が原理的に発生しません。

---

## 🎯 2. なぜ「3 つの方法（課題）」を理解する必要があるのか？

オライリー本 181 ページの箇条書き 3 点は、**「実務で使える回答抽出システムを構築するための 3 つの技術的ハードル（壁）」** を意味しています。

```text
 ［ 壁 1: 予測の仕組みの理解 ］ ──> 教師あり学習の枠組み (スパン分類)
   ・どうやってAIに「開始位置」と「終了位置」の 2 つの数字を同時に予測させるか？

 ［ 壁 2: 入力フォーマット ］ ──> トークン化とエンコード
   ・質問と本文という2つのテキストを、どうやって `[CLS] 質問 [SEP] 本文 [SEP]` として1本に連結して入力するか？

 ［ 壁 3: 長文トラブル対策 ］ ──> 長いパッセージの処理
   ・レビュー文が長すぎてモデルの上限 (512トークン) を超えた時、どうやって「窓をずらしながら (スライディングウィンドウ)」全体を漏れなく読み込ませるか？
```

## 🧩 3. スパン分類用のヘッドの構造 (182 ページ図7-4)

トークン分類（第4章のNER）では各単語に対して 7 つのクラス（`B-PER` など）を予測していましたが、スパン分類（第7章のQA）では **各トークンに対して「開始スコア」と「終了スコア」の 2 つの数値（ロジット）を出力する全結合層 (`nn.Linear(hidden_size, 2)`)** を載せます。

```python
# スパン分類ヘッドの実体イメージ
self.qa_outputs = nn.Linear(config.hidden_size, 2)
# 出力 shape: [batch_size, seq_len, 2]
#  -> 2つの値のうち、一方が「開始スコア」、もう一方が「終了スコア」
```

---

## 📝 まとめ

* **生成ではなく範囲指定**: 抽出型 QA は「文字の生成」ではなく「本文のスタート位置とゴール位置の 2 つの数字を当てるタスク」。
* **3つの課題の意味**: システムを構築するために「①範囲指定の原理」「②質問＋本文の連結ルール」「③長文の分割・窓ずらし」を順番にクリアしていく必要がある。
