# BERTにおける特殊トークン `[SEP]` (Separator) の役割

BERT系モデルのトークナイザーが自動的に追加する **`[SEP]` (Separator Token)** の正体と役割について解説します。

---

## 1. 結論：`[SEP]` トークンとは？

`[SEP]` は **Separator（セパレーター / 区切り文字）** の略で、**「文章の終わり（終端）」** や **「2つの文章の境界（区切り）」** をモデルに知らせるための特別な記号（特殊トークン）です。

---

## 2. `[SEP]` の 2 つの役割

### 役割①：2つの文章の「境界（仕切り）」を示す
BERT は「2つの文章の関係性を判定するタスク（質問応答や類似度判定など）」が得意です。その際、どこからどこまでが第1文で、どこからが第2文なのかを区切る仕切りとして使われます。

```text
 ［ 入力ペア ］: 
   文1: "What is your favorite food?" (質問)
   文2: "I like sushi." (回答)

 ［ トークナイザーの出力結果 ］:
   [CLS] What is your favorite food? [SEP] I like sushi. [SEP]
                                      ▲                 ▲
                                    文の区切り        全体の末尾
```

### 役割②：単一文章の「終端記号（ピリオドのような役割）」を示す
1つの文章だけを入力するタスク（第2章で行った感情分類など）であっても、BERT は文章の終わりを認識するために、末尾に自動的に `[SEP]` を付与します。

```text
 ［ 単一入力 ］: "I love learning AI."

 ［ トークナイザーの出力結果 ］:
   [CLS] I love learning AI. [SEP]
                              ▲
                             文章の終了を明示
```

---

## 3. BERT の 2 大特殊トークン (`[CLS]` と `[SEP]`)

| 特殊トークン | 正式名称 | 挿入位置 | 主な役割 |
| :--- | :--- | :--- | :--- |
| **`[CLS]`** | Classification | 文章の**先頭** | 文章全体の意味・要約ベクトルを集約する |
| **`[SEP]`** | Separator | 文章の**区切り・末尾** | 文の境界線や文章の終了地点をモデルに教える |

---

## 4. まとめ

`[SEP]` は、モデルがテキストを処理する際に **「ここが1つ目の文の終わりですよ」「ここがテキスト全体の終了地点ですよ」** という構造を正しく理解させるための標識（目印）です。
